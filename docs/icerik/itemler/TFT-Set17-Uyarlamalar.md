# TFT Set 17 FRP Eşya Uyarlamaları

Bu katalog, 8 Ağustos 2026 tarihinde aktif olan TFT Set 17 ile birlikte erişilebilen ortak, birleşik, Işıltılı, Eser, Destek, Amblem ve sete özel ekipmanları FRP sistemine uyarlar. Sistem belirteçleri, şampiyon kopyaları, pazar teklifleri ve debug kayıtları dahil edilmez.

- Seçilen ham kayıt: 242
- Benzersiz eşya: 240
- Set: Space Gods / Set 17

## Kullanım sınırları

- LoL kataloğundaki Eşya Bağı, Eşya Darbesi ve Eşya Savunması sınırları aynen geçerlidir.
- Işıltılı ve Eser eşyalar aynı anda en fazla birer tane bağlanabilir.
- Amblem yeni sınıf vermez; yalnızca tematik Aspect ve savaş dışı Invoke sağlar.
